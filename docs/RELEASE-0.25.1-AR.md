# M 0.25.1 — ملاحظات الإصدار

## إصلاحات الاستخدام والوسائط

- إضافة مسارات واضحة لبدء ربط Facebook وInstagram عبر Meta OAuth، وX وLinkedIn وTikTok وYouTube عبر موصلات OAuth الموجودة، مع إبقاء WhatsApp Business وTelegram ضمن مسار الإعداد الخاص بهما.
- إضافة روابط تفتح مواقع Gmail وGoogle وFacebook وInstagram وTikTok وYouTube وX وLinkedIn وTelegram وWhatsApp Web في المتصفح مباشرة.
- إضافة زر لتشغيل ملفات الفيديو المرفوعة في مكتبة الوسائط بمشغّل HTML5 محلي، باستخدام جلسة M للوصول إلى الملف.
- توحيد نسخة البرنامج ومخبأ PWA ونسخة المثبت مع 0.25.1.
- نجحت اختبارات الجودة واختبارات المتصفح على تغييرات الإصدار 0.25.1 قبل الدمج.

## متطلبات تبقى خاصة بحساب المستخدم

- فتح موقع المنصة لا يعني أن الحساب متصل داخل M.
- يلزم إعداد تطبيقات المطور الرسمية وبيانات OAuth وعناوين العودة والصلاحيات المطلوبة؛ لا تُرسل المفاتيح أو رموز الوصول إلى المحادثة.
- Google OAuth يتيح هوية Google فقط بالنطاقات المهيأة له، ولا يمنح تلقائيًا صلاحية Gmail أو YouTube أو بقية منتجات Google.
- قدرات النشر وقراءة المحتوى تختلف حسب الموصل. لا يتضمن هذا الإصدار نشر الفيديو على TikTok أو YouTube أو Instagram؛ معاينة الفيديو المحلي لا تعني نشره.
- يبقى نشر المحتوى الخارجي متوقفًا افتراضيًا حتى يفعّله مالك النشر بعد اختبار حساباته وصلاحياته.
