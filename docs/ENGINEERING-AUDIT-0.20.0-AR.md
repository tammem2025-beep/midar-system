# تقرير هندسي — M 0.20.0

## نطاق هذه الدفعة

تم تجهيز نسخة مطورة من المصدر المرسل (0.19.0) تحت هوية **M — Digital Business Management**. تركز هذه الدفعة على تحويل الهوية البصرية إلى أصول ونظام تصميم متصلين بالواجهة القائمة، وتقليل التكرار المرئي، وتحسين ربط الثيم دون إعادة كتابة المشروع من الصفر.

## التغييرات المنفذة

### الهوية والأصول
- إنشاء رمز M متجهي مستقل وقفل شعار أفقي.
- تحديث شعار التطبيق وfavicon وأيقونات PNG وبيانات PWA.
- تحديث الاسم الظاهر ووصف المنتج والعنوان والبيانات الوصفية والتذييل.
- إضافة لوحة هوية بصرية ومواصفة عربية ضمن ملفات المشروع.

### التصميم وتجربة الاستخدام
- إضافة `frontend/styles-src/14-m-brand-identity.css` كطبقة الهوية الأخيرة.
- تعريف توكنات مركزية للألوان والأسطح والنصوص والحدود واللمسات.
- ربط الخيارات الستة للألوان بالتوكنات وبالمتغيرات القديمة التي تستخدمها وحدات الواجهة الحالية.
- توحيد المظهر الأساسي للوحة القيادة والتقويم والإعدادات والمكونات المشتركة.
- ضبط ارتفاع الرأس إلى 60px على الكمبيوتر و56px في الشاشات الصغيرة ضمن الطبقة الجديدة.
- إخفاء كتلة الحساب/تسجيل الخروج المكررة في ذيل القائمة الجانبية، مع الإبقاء على عناصر DOM القديمة للتوافق؛ تظل إدارة الحساب وتسجيل الخروج متاحة من قائمة الحساب في الرأس.
- جعل اللون الأزرق هو fallback عند تعذر تحميل تفضيلات المظهر، دون استبدال التفضيلات المخزنة للمستخدمين الحاليين.
- ربط حالات تحديد عناصر القائمة الجانبية باللون الأساسي المختار، مع إبقاء ألوان حالات النجاح والتحذير والخطأ دلالية.

### الهندسة والتوافق
- إعادة بناء CSS المجمّع من 15 وحدة مصدر.
- تحديث إصدار التطبيق إلى 0.20.0 ومراجع cache busting واسم cache الخاص بالخدمة.
- تحديث بيانات الإصدار في API وبعض رسائل/بيانات التكامل.
- إضافة مشغل Windows باسم `run-m-windows.ps1`، مع الإبقاء على مشغل الاسم القديم كاختصار متوافق، وإصلاح إعادة تعيين حالة إنشاء البيئة الافتراضية في المشغل الجديد.
- إضافة `.gitignore` لاستبعاد ملفات البيئة المحلية وقواعد البيانات والكاش.
- إضافة دليل بدء سريع، وسجل تغييرات، واختبارات لنظام الهوية البصرية.

## نتائج التحقق في بيئة الإعداد

- `pytest -q`: **64 اختبارًا ناجحًا**.
- `python -m compileall -q backend`: نجح.
- `node --check` على ملفات JavaScript في المجلد الأساسي للواجهة: نجح.
- `python tools/build_frontend_css.py`: أعاد بناء 15 وحدة CSS بحجم يقارب 252 KB.
- ملف `manifest.webmanifest`: تمت قراءة JSON والتحقق من الاسم والحقول الأساسية.
- ملفات SVG: اجتازت تحليل XML.
- أيقونات PNG: تم التحقق من الأبعاد 192×192 و512×512 و180×180 وسلامة الملفات.
- معاينة المتصفح: لا أخطاء JavaScript في صفحة المعاينة؛ لم يظهر تمرير أفقي في معاينة الهاتف بعرض 390px.
- اختبار الثيم: تم التأكد من أن تبديل اللون الأساسي يغيّر `--md-accent` لكل الخيارات الستة، وأن خلفية عنصر القائمة النشط تعتمد على اللون المختار.
- فحص دخان لـ API أثناء إعداد الإصدار: أعاد `/api/v1/health` الحالة `ok` وإصدار `0.20.0` وقاعدة البيانات `ok` في بيئة اختبار محلية.

## حدود التحقق

هذه نتائج تحقق ضمن بيئة الإعداد، وليست شهادة أمان مستقلة أو اختبار تحميل إنتاجي. صور المعاينة تستخدم أرقامًا وبيانات توضيحية وليست بيانات تشغيل حقيقية أو اتصالًا حيًا بحسابات اجتماعية.

لم يتم التحقق قانونيًا من توافر علامة M أو النطاقات أو أسماء الحسابات. كما أن إعادة الهوية لا تعني أن كل موصلات Meta أو Instagram أو WhatsApp أو X مكتملة أو معتمدة؛ المتاح لكل منصة تحكمه الشيفرة المنفذة وصلاحيات المزود ومراجعته.

## التوصية قبل التحديث المحلي أو الإطلاق

1. احتفظ بنسخة احتياطية من المصدر الحالي وقاعدة البيانات وملف `.env`.
2. فك الحزمة في مجلد جديد واختبرها منفصلة قبل استبدال النسخة الحالية.
3. راجع إعدادات البيئة المحلية ولا تشارك الأسرار.
4. اختبر تسجيل الدخول، قائمة الحساب، الثيم الفاتح والداكن، خيارات اللون، والصفحات الأساسية.
5. تحقق من حالة الخدمة بعد تحديث ملفات الواجهة، خصوصًا مع وجود Service Worker قد يحتفظ بأصول قديمة.
6. لا تنقل قاعدة البيانات أو تغيّر إعدادات الإنتاج قبل مراجعة متطلبات بيئتك.
