# تشغيل مِدار على Windows وAndroid وiPhone

## الحالة الحالية

مِدار في هذا الإصدار تطبيق ويب متجاوب يدعم PWA؛ ليس ملف APK أو تطبيق iOS أصليًا منشورًا في المتاجر. يمكن فتحه على المتصفحات الحديثة، وتثبيته كتطبيق عندما يدعم المتصفح ذلك. تتطلب تجربة مشتركة بين الأجهزة استضافة يمكن الوصول إليها من كل جهاز، ويفضّل HTTPS.

## Windows

افتح رابط مِدار في Microsoft Edge أو Chrome، ثم استخدم خيار المتصفح لتثبيت الموقع كتطبيق إذا ظهر. للحصول على تحديثات موثوقة، يجب الوصول إلى الخادم عبر عنوان ثابت وآمن.

## Android

افتح رابط مِدار في Chrome، ثم استخدم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» إذا كان الخيار متاحًا. تتطلب مزايا PWA وسيرفس ووركر سياقًا آمنًا (HTTPS، باستثناء localhost).

## iPhone وiPad

افتح الرابط في Safari، ثم «مشاركة» واختر «إضافة إلى الشاشة الرئيسية». لا يدعم Safari حدث التثبيت البرمجي نفسه المستخدم في Chrome، لذلك يعرض مِدار تعليمات يدوية.

## ملاحظات مهمة

- تثبيت PWA لا يجعل التطبيق يعمل دون الخادم؛ طلبات API تحتاج إلى اتصال بالخادم.
- الوصول من هاتف إلى خادم يعمل على `127.0.0.1` في حاسوب Windows لن يعمل، لأن `localhost` على الهاتف يشير إلى الهاتف نفسه. تحتاج إلى استضافة آمنة يمكن الوصول إليها من الهاتف.
- لا تفتح خادم التطوير على شبكة عامة. قبل الإنتاج يلزم HTTPS، إعدادات نشر آمنة، مراجعة الجلسات والصلاحيات، المراقبة والنسخ الاحتياطية.
- بناء تطبيقات أصلية للمتاجر باستخدام Capacitor أو إطار متعدد المنصات قرار لاحق مستقل؛ هذا الإصدار يحسن تجربة الويب/PWA ولا يقدّم حزم متجر أصلية.
