# M 0.25.2 — ملاحظات الإصدار

## فتح الصفحات المرتبطة بكل سجل حساب

- يضيف عمود الإجراءات زر «فتح الصفحة» لكل حساب مسجل؛ يستخدم الرابط الرسمي الموجود في خانة المعرّف إذا كان نطاقه موثوقًا، أو يبني رابطًا من اسم المستخدم للمنصات المدعومة.
- الروابط تفتح عبر HTTPS في تبويب منفصل، مع رفض بروتوكولات ونطاقات غير موثوقة.
- يستمر زر «عرض المحتوى الحقيقي» في عرض المحتوى عندما يكون موصل المنصة متصلاً ومصرحًا له.

## النطاق والقيود

- يظل تسجيل حساب يدويًا مختلفًا عن توصيل حساب حقيقي؛ يلزم OAuth رسمي أو إعداد Bot/Business API والصلاحيات المطلوبة.
- فتح صفحة حساب في المتصفح لا يضيف صلاحيات قراءة أو نشر داخل M.
- لا يضيف هذا الإصدار نشر فيديو خارجيًا إلى Instagram أو TikTok أو YouTube؛ تشغيل الفيديو المحلي في مكتبة الوسائط مدعوم في 0.25.1.
