# تشغيل وتثبيت M على Windows والجوال

## 1. مثبت Windows

**صفحة التنزيل الرسمية:** https://github.com/tammem2025-beep/midar-system/releases/latest

افتح أحدث إصدار، ثم من قسم **Assets** نزّل ملف `.exe`، مثل `M-Setup-0.22.0-Windows-x64.exe`. لا تختَر `Source code (zip)` أو `Source code (tar.gz)`؛ فهما ملفات مصدر وليسا مثبّت ويندوز.

المثبّت مخصص لـ Windows 64-bit ولا يحتاج إلى Python مثبتًا عند المستخدم. بعد تشغيله وإكمال الخطوات، افتح M من قائمة Start أو من اختصار سطح المكتب إذا اخترت إنشاءه.

المثبّت غير موقّع حاليًا بشهادة ناشر رقمية؛ قد يظهر تحذير Windows SmartScreen. تحقق من أن الملف من صفحة الإصدارات الرسمية ومن أن بناء المثبّت اكتمل بنجاح.

إذا لم يظهر ملف `.exe` ضمن Assets، افحص [آخر تشغيل لبناء مثبت Windows](https://github.com/tammem2025-beep/midar-system/actions/workflows/release-windows.yml) وتأكد من أن نتيجته **Success**.

## 2. أين تُحفظ البيانات؟

تبقى قاعدة البيانات والوسائط والإعدادات خارج مجلد البرنامج، داخل:

%LOCALAPPDATA%\M\

يشمل ذلك قاعدة البيانات تحت data\m.db، والوسائط تحت data\media، وملف الإعدادات السري .env والسجلات. تحديث البرنامج لا يفترض أن يحذف هذه البيانات، كما أن إزالة البرنامج لا تحذفها عمدًا.

قبل أي تحديث مهم، أغلق M وأنشئ نسخة احتياطية من مجلد %LOCALAPPDATA%\M\. لا ترفع ملف .env أو قاعدة البيانات إلى GitHub.

## 3. تشغيل المصدر محليًا

داخل مجلد المصدر استخدم الأمرين التاليين في PowerShell:

    Set-ExecutionPolicy -Scope Process Bypass -Force
    .\run-m-windows.ps1

ثم افتح http://127.0.0.1:8000.

## 4. معاينة من هاتف على شبكة Wi-Fi نفسها

على جهاز Windows المضيف شغّل:

    Set-ExecutionPolicy -Scope Process Bypass -Force
    .\run-m-windows.ps1 -LAN

سيعرض المشغّل عناوين IPv4 المحتملة. على الهاتف افتح العنوان الذي يطابق شبكة Wi-Fi، مثل http://192.168.x.x:8000. إذا منع جدار حماية Windows الاتصال، اسمح بالمنفذ على الشبكة الخاصة فقط بعد التحقق من الشبكة.

هذا الوضع للمعاينة المحلية فقط: الاتصال HTTP غير مشفر، وقد تحتاج إلى السماح للمنفذ عبر جدار الحماية. لا تستخدمه على شبكة عامة، ولا تعرضه مباشرة للإنترنت، ولا تعتبره عنوان تثبيت PWA نهائيًا.

## 5. تثبيت واجهة PWA على Android وiPhone وكمبيوتر

يحتاج التثبيت عبر المتصفح إلى عنوان HTTPS عام موثوق (باستثناء localhost على الجهاز نفسه). عنوان LAN عبر HTTP مفيد للمعاينة، لكنه لا يكفي لتثبيت PWA على الهاتف. بعد نشر الخادم على استضافة HTTPS مع قاعدة بيانات دائمة وأسرار إنتاج صحيحة:

- **Android / Chrome:** افتح رابط M واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية» من قائمة المتصفح.
- **Windows / Edge أو Chrome:** افتح رابط HTTPS واختر «تثبيت M» عند ظهور الخيار.
- **iPhone / iPad:** افتح الرابط في Safari، ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية».

PWA هي واجهة تطبيق الويب المثبتة؛ لا تعني أن النشر الاجتماعي أو الجدولة الخلفية أصبحا مدعومين تلقائيًا.

## 6. الحدود التي تحتاج إعدادًا خارجيًا

تسجيل Google هو لتسجيل الدخول إلى M وليس ربط حسابات Instagram أو Facebook. ما زال كل موصل اجتماعي بحاجة إلى OAuth/API وموافقات وصلاحياته الرسمية. قبل أي نشر عام، يجب إكمال مراجعة قاعدة البيانات والترحيلات، HTTPS، حماية الجلسات، النسخ الاحتياطي/الاستعادة، ومراقبة الأخطاء.

راجع docs/PRODUCTION-CHECKLIST.md وdocs/MOBILE-PWA-SETUP-AR.md قبل نشر رابط HTTPS حقيقي.
