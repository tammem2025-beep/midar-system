# M — Digital Business Management

**Manage. Connect. Grow.**  
منصة لإدارة الأعمال الرقمية والمحتوى والتواصل. الإصدار المقترح على فرع التطوير: **0.26.0** (قيد المراجعة، غير منشور كإصدار رسمي بعد).

## ما يتضمنه المشروع

### تجربة مركز الشبكات الاجتماعية — 0.26.0 (قيد المراجعة)

- أزيل شريط الروابط العلوي المكرر الذي كان يفتح صفحات المنصات في تبويبات خارجية.
- أصبحت أيقونات بطاقات المنصات وأسماؤها نقطة الدخول إلى مساحة العمل داخل M: تعرض المحتوى الحقيقي للحسابات المتصلة حيث يسمح موصل API، أو تبدأ تدفق الربط الرسمي عندما لا يكون الحساب متصلًا.
- أضيف اختيار داخلي للحساب عندما تكون هناك عدة حسابات متصلة للمنصة نفسها.
- تم تحسين طبقة التصميم المرئية مع الحفاظ على الوضع الداكن/الفاتح وألوان العلامة القابلة للتخصيص.
- تظل شاشات موافقة OAuth الرسمية خارج التطبيق عند الحاجة، ولا يُدّعى دعم الموجز الكامل أو التفاعلات التي لا توفرها واجهات المنصات الرسمية.

### تصحيح وظائف الربط والوسائط — 0.25.1

- أضيفت أزرار بدء الربط الرسمي مباشرة إلى بطاقات المنصات، باستخدام مسارات OAuth الموجودة في الخادم، بدل أن يبقى المستخدم في شاشة تعرض الحالة دون طريق واضح للربط.
- أضيفت روابط مباشرة لفتح Gmail وحساب Google وFacebook وInstagram وTikTok وYouTube وX وLinkedIn وTelegram وWhatsApp Web في المتصفح. هذه الروابط تفتح المواقع الأصلية فقط ولا تعني اتصال الحساب داخل M.
- أضيف زر تشغيل لملفات الفيديو الموجودة محليًا في مكتبة الوسائط باستخدام جلسة المستخدم، مع مشغّل HTML5.
- تبقى وظائف النشر/قراءة المحتوى محدودة حسب موصل كل منصة. OAuth لن يعمل قبل وضع بيانات المطوّر في `.env` ومنح الصلاحيات المطلوبة؛ إضافة سجل حساب ليست ربطًا فعليًا.


- لوحة تشغيل، وإدارة المنشورات وتقويم المحتوى، ومكتبة الوسائط، والمهام، والعملاء، والحملات، والفريق والصلاحيات، وسجل النشاط.
- هوية M ومظهر داكن/فاتح وألوان قابلة للتخصيص.
- تبديل محلي بين العربية والإنجليزية مع تغيير اتجاه الواجهة RTL/LTR. ترجمة بعض النصوص الديناميكية في المجالات المختلفة ما زالت تحتاج تغطية واختبارًا إضافيين.
- واجهة PWA قابلة للتثبيت عندما تُخدم من عنوان HTTPS مناسب.
- موصلات رسمية جزئية بحسب الصلاحيات: قراءة صفحات Facebook وInstagram الاحترافي، نشر النص على Facebook وX وLinkedIn وTelegram، وقراءة ملفات/محتوى X وTikTok وYouTube المتاح.
- موصل WhatsApp Business Cloud API للتحقق من رقم الأعمال، استقبال الرسائل عبر Webhook موقّع، وإرسال ردود نصية. لا يعني ذلك اكتمال النشر بالوسائط أو كل وظائف كل منصة؛ الجدولة التلقائية تغطي فقط الموصلات التي تنفذ نشر النص حاليًا.
- مشغّل Windows، وضع LAN للمعاينة، بيانات عرض مستقلة، ومشروع بناء لمثبت Windows x64.
- CI لاختبارات Python وCSS وJavaScript، واختبارات Playwright للمتصفح.

## تشغيل المصدر على Windows

المتطلبات: Python 3.12 أو 3.13، وPowerShell. من جذر المشروع:

    Set-ExecutionPolicy -Scope Process Bypass -Force
    .\run-m-windows.ps1

ثم افتح http://127.0.0.1:8000 واترك نافذة PowerShell مفتوحة. يُنشئ المشغّل .env محليًا بمفتاح عشوائي إن لم يكن موجودًا، ولا يستبدل ملف إعدادات موجودًا.

### معاينة من هاتف على شبكة Wi-Fi نفسها

للمعاينة فقط على شبكة منزلية خاصة وموثوقة:

    .\run-m-windows.ps1 -LAN

استخدم عنوان IPv4 الذي يطبعه المشغّل، مع المنفذ 8000، على هاتف متصل بالشبكة نفسها. LAN هنا HTTP غير مشفر، وليس إعدادًا إنتاجيًا؛ لا تستخدمه على شبكة عامة أو مع بيانات حساسة.

## عرض تجريبي جاهز

الرابط: http://127.0.0.1:8001  
البريد: demo-owner@example.com  
كلمة المرور: Demo-M-Only-2026!

هذه بيانات عرض عامة ومقصودة للنسخة المحلية فقط. يُنشأ مجلد demo-data مستقل وغير مرفوع إلى Git. جميع الحسابات الاجتماعية في العرض غير متصلة، والرسائل محلية فقط. لا تستخدم هذه الحسابات على استضافة عامة ولا مع بيانات حقيقية. راجع DEMO-GUIDE-AR.md.

## مثبت Windows

**إعادة بناء موثقة في 25 أكتوبر 2026:** أُعيد بناء مثبت Windows والحزمة المحمولة من آخر commit، واجتازا اختبارات Python وJavaScript والبناء. تتضمن الحزم ملف `SHA256SUMS.txt` للتحقق من سلامة التنزيل. 

**محتوى إصدار 0.25.1:** يضيف عامل جدولة للمنشورات المستحقة مع منع التكرار عند التنافس بين العمليات، إلى جانب موصلات 0.24.0 للنشر النصي على Facebook وX وLinkedIn وTelegram وربط OAuth/قراءة المحتوى المدعوم وWhatsApp Business. تتطلب الوظائف إعداد تطبيقات المطور والصلاحيات على حسابك؛ النشر الخارجي يبقى متوقفًا حتى تضبط `ENABLE_EXTERNAL_PUBLISHING=true`. توقيع Authenticode يتطلب شهادة ناشر موثوقة؛ إن لم تُضبط شهادة في GitHub Secrets فسيظل المثبت غير موقّع وقد يعرض SmartScreen تحذيرًا.


آخر إصدار منشور موثق هنا هو **M 0.25.1**؛ أما تحديث **M 0.26.0** فهو على فرع مراجعة منفصل ولم يُنشر كإصدار رسمي بعد. تعليمات إعداد كل مزوّد ومفاتيح OAuth وWebhook موجودة في [دليل ربط المنصات الاجتماعية](docs/SOCIAL-INTEGRATIONS-SETUP-AR.md)، مع دليل [إعداد Google وMeta](docs/META-GOOGLE-CONNECTION-SETUP-AR.md).

**صفحة التنزيل الرسمية:** [تحميل أحدث إصدار من M لويندوز](https://github.com/tammem2025-beep/midar-system/releases/latest)

### حزمة Windows المحمولة (ضمن الإصدار الحالي)

إلى جانب المثبّت، يبني سير العمل حزمة مجلد ZIP باسم `M-Windows-x64-Portable` بعد نجاح GitHub Actions. افتح [آخر تشغيل لسير عمل Windows](https://github.com/tammem2025-beep/midar-system/actions/workflows/release-windows.yml)، ثم نزّل ملف **Artifacts → M-Windows-x64-Portable**، وفكّه كاملًا داخل مجلد لديك صلاحية الكتابة فيه، ثم شغّل `M.exe`.

تستخدم هذه الحزمة مجلد `M-Portable-Data` بجانب البرنامج لحفظ الإعدادات وقاعدة البيانات والوسائط والسجلات؛ أما المثبّت العادي فيستمر بحفظ بياناته في `%LOCALAPPDATA%\\M\\`. الحزمة المحمولة أرشيف ZIP يحتوي ملفات البرنامج وليست ملف EXE منفردًا. تبقى النسخة `0.25.1`؛ هذه تحسينات على الفرع الحالي وليست إصدارًا مستقلًا. مدة الاحتفاظ بـ Artifact محدودة، لذا نزّل نسخة احتياطية من مجلد البيانات.

بعد فتح صفحة الإصدار، من قسم **Assets** نزّل ملف التثبيت الذي ينتهي بـ `.exe`، مثل `M-Setup-0.25.1-Windows-x64.exe`. لا تنزّل `Source code (zip)` أو `Source code (tar.gz)`؛ هذه أرشيفات للمصدر وليست برنامج التثبيت.

- شغّل ملف `.exe` واتبع خطوات التثبيت.
- لا تحتاج إلى تثبيت Python على جهازك.
- المثبّت مخصص لويندوز 64-bit.
- قد يعرض Windows SmartScreen تحذيرًا لأن المثبّت غير موقّع بعد بشهادة ناشر. تأكد أن التنزيل من صفحة M الرسمية قبل المتابعة.

تُحفَظ قاعدة البيانات والوسائط وملف الإعدادات محليًا تحت `%LOCALAPPDATA%\\M\\` خارج مجلد البرنامج، حتى لا يحذفها تحديث البرنامج أو إزالته عمدًا. أغلق M وخذ نسخة احتياطية من هذا المجلد قبل أي تحديث مهم، ولا تحذف محتوياته يدويًا.

إذا لم يظهر ملف التثبيت ضمن **Assets**، افتح [سير عمل بناء مثبت Windows](https://github.com/tammem2025-beep/midar-system/actions/workflows/release-windows.yml) وتحقق من أن آخر تشغيل انتهى بنتيجة **Success**؛ قد يحتاج النشر إلى اكتمال البناء أولًا.

إذا نجح بناء المثبّت لكن لم تظهر صفحة Release، نزّل الحزمة ZIP من قسم **Artifacts** في أحدث تشغيل لسير العمل أعلاه؛ يكون ملف `M-Setup-0.25.1-Windows-x64.exe` داخلها. وللسماح للـ Release الرسمي بالإنشاء تلقائيًا، تأكد من إعدادات المستودع **Settings → Actions → General → Workflow permissions → Read and write permissions** ثم أعد تشغيل سير العمل.

## التثبيت على الجوال والكمبيوتر عبر PWA

PWA يثبت واجهة الويب، ولا يحوّلها إلى تطبيق أصلي منشور في متاجر Apple/Google. يلزم عنوان HTTPS يمكن للجهاز الوصول إليه:

- Android/Chrome: قائمة المتصفح ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- Windows/Edge أو Chrome: افتح رابط HTTPS واختر «تثبيت M».
- iPhone/iPad: افتح الرابط في Safari ← «مشاركة» ← «إضافة إلى الشاشة الرئيسية».

لا يوجد في هذا المستودع رابط عام مستضاف لـ PWA حتى الآن. وضع LAN للمعاينة HTTP فقط ولا يكفي للتثبيت الرسمي على الهاتف.

## حدود التشغيل الواقعية

- تسجيل Google يخص هوية الدخول إلى M؛ لا يمنح تلقائيًا صلاحية إدارة Instagram/Facebook/WhatsApp أو خدمات Google الأخرى. لإدارة حسابات التواصل، يجب إكمال OAuth والصلاحيات الرسمية لكل منصة على حدة.
- Facebook: ربط وقراءة صفحات ونشر منشورات نصية بعد منح `pages_manage_posts`.
- Facebook: قراءة الصفحات ونشر النص؛ الصور والفيديو غير مفعلة.
- Instagram: قراءة وسائط الحسابات المهنية المؤهلة فقط؛ نشر Instagram والرسائل غير مفعّلين.
- X: ربط الحساب وقراءة المنشورات المتاحة ونشر النص إذا منح الحساب `tweet.read` و`tweet.write`.
- LinkedIn: ربط ملف العضو ونشر النص إذا منح `w_member_social`؛ ملف المؤسسة وقراءة منشورات الأعضاء ليست ضمن هذا الموصل.
- TikTok: ربط الحساب وقراءة الفيديوهات المتاحة؛ النشر يحتاج موافقة المنتج ونطاق `video.publish` ومسار رفع لم يُنفّذ بعد.
- YouTube: ربط القناة وقراءة الفيديوهات المتاحة؛ رفع الفيديو يتطلب مسارًا منفصلًا لم يُنفّذ بعد.
- WhatsApp Business: تحقق الرقم، استقبال رسائل نصية وردود نصية عبر Cloud API بعد إعداد Webhook عام HTTPS؛ لا يدعم WhatsApp الشخصي، وقوالب الرسائل والوسائط لم تُنفّذ.
- Telegram: تحقق من القناة ونشر النص فقط؛ استقبال تحديثات البوت والوسائط غير مفعّلين.
- **الجدولة التلقائية متاحة أثناء تشغيل M**: يعالج العامل المنشورات المستحقة كل 15 ثانية افتراضيًا، بشرط أن تكون حالتها `scheduled` وأن يكون `ENABLE_EXTERNAL_PUBLISHING=true`. إذا أُغلق التطبيق يتوقف العامل، ويعالج المواعيد المتأخرة عند تشغيله مجددًا. النشر الآلي متاح فقط للموصلات النصية المنفذة (Facebook وX وLinkedIn وTelegram)؛ ولا تعني الجدولة دعم الصور/الفيديو أو كل المنصات.
- لا يوجد رابط PWA عام أو APK/IPA أصلي منشور في هذا المستودع بعد. يلزم استكمال HTTPS الإنتاجي، وإدارة تدوير رموز الوصول، وفحص الأمان، والنسخ الاحتياطي/الاستعادة قبل خدمة SaaS عامة.
